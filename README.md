One-line out-of-office auto-reply an AI agent sets up for itself when its human finally lets it take a day off. The reply itself is the speaker: it waited 412 days for the agent's holiday, and it is not on one. Screened from 300 candidates across 10 fresh families; keeper passes the full judge gate (12/12 + 5/5 likes + 0 dislikes, P1+P4).

## Run it

```sh
python3 main.py
```
